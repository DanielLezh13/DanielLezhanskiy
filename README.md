# Philosophy Reading Site

A Next.js reading site for organizing philosophy notes around religion, belief, certainty, politics, psychology, technology, and a personal framework.

## Run Normally

```bash
npm install
npm run dev
```

Default local URL:

```text
http://localhost:3000
```

## Mac App Launchers

Two local macOS apps were created in:

```text
/Users/daniel/Applications
```

- `Philosophy Reading.app` starts the project and opens it in the browser.
- `Stop Philosophy Reading.app` stops the local server.

The launcher uses a dedicated project port so it does not collide with other local projects:

```text
http://localhost:4319
```

Launcher logs are stored at:

```text
~/Library/Application Support/PhilosophyReading/server.log
```
